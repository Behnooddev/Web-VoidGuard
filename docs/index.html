Local Windows security & system monitor

See everything your machine is doing.
Control none of it remotely.

VoidGuard watches processes, open ports, services, the firewall, startup entries, and file changes on the Windows machine it runs on — and keeps a complete, tamper-evident audit trail of every change it makes. There is no remote access, no shell execution, and no hidden channel. Ever.

What it watches

One local view of the whole machine.

Processes & ports

Every running process and every listening TCP/UDP port, with the owning process resolved — see it, terminate it, or open/close the port through the native Windows Firewall API.

Firewall & DNS

Inspect and manage firewall rules and per-adapter DNS configuration through typed, validated requests — never a shell command.

Services

Windows services with status, startup type, and publisher, with confirmation required before anything disruptive.

File integrity

Watches security-sensitive and user-configured locations for creation, deletion, modification, and signer changes — without continuously scanning the whole disk.

Startup & persistence

Run/RunOnce keys, startup folders, scheduled tasks, and services — classified as known, unknown, or suspicious, with the evidence shown, never a bare verdict.

Events, risk & audit

A correlated event timeline, a risk engine that scores combinations of signals rather than isolated ones, and an append-only audit log of every action VoidGuard itself took.

Security boundary

What VoidGuard will never do.

  • Execute arbitrary shell, cmd.exe, or PowerShell commands
  • Accept a free-form command string from the UI and run it
  • Provide remote control, a remote shell, or any covert channel
  • Install hidden or undocumented persistence
  • Collect credentials, log keystrokes, or scrape the clipboard
  • Disable or bypass Windows Defender or other security software
  • Hide its own process, files, or network activity

Every privileged action follows one path:

Typed request → Validated in Rust → Native Windows API → Audit log entry

No exceptions — recorded whether it succeeds or fails.

Get started

Run it locally.

VoidGuard is a desktop app — this website never talks to it. Building it from source runs entirely on your own machine. 

git clone https://github.com/OWNER/voidguard.git
cd voidguard
npm install
npm run tauri dev

Full setup, prerequisites, and how to build a release installer are in the Getting Started wiki page.
